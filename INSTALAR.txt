DEVFLOW SCANNER 1.5.4 — EXTENSIÓN GRATUITA PARA VS CODE

ELIGE UN SOLO ARCHIVO
- Windows 64 bits: DevFlow-Scanner-win32-x64-1.5.4.vsix
- Mac Intel: DevFlow-Scanner-darwin-x64-1.5.4.vsix
- Mac Apple Silicon M1/M2/M3/M4: DevFlow-Scanner-darwin-arm64-1.5.4.vsix

INSTALACIÓN
1. Abre Visual Studio Code.
2. Abre el panel Extensiones.
3. En el menú de tres puntos, elige "Instalar desde VSIX...".
4. Selecciona el archivo correspondiente al equipo.
5. Abre una carpeta de proyecto y confía en el workspace.
6. Pulsa el ícono lateral de DevFlow para abrir directamente el scanner.

NOVEDADES
- Buscador avanzado disponible en todos los proyectos con endpoints.
- Filtros por método, ruta, componente y rol sin importar el tamaño del proyecto.
- Menú en primer plano, altura controlada y acceso lateral de un clic.

VALIDACIÓN
- Windows x64: instalado y probado correctamente.
- Mac Intel/Apple Silicon: compilado de forma cruzada; requiere prueba final en una Mac real.
