DEVFLOW SCANNER 1.4.3 — EXTENSIÓN GRATUITA PARA VS CODE

ELIGE UN SOLO ARCHIVO
- Windows 64 bits: DevFlow-Scanner-win32-x64-1.4.3.vsix
- Mac Intel: DevFlow-Scanner-darwin-x64-1.4.3.vsix
- Mac Apple Silicon M1/M2/M3/M4: DevFlow-Scanner-darwin-arm64-1.4.3.vsix

INSTALACIÓN
1. Abre Visual Studio Code.
2. Abre el panel Extensiones.
3. En el menú de tres puntos, elige "Instalar desde VSIX...".
4. Selecciona el archivo correspondiente al equipo.
5. Abre una carpeta de proyecto y confía en el workspace.
6. Pulsa "DevFlow" en la barra inferior o ejecuta "DevFlow: Abrir Scanner" desde la paleta de comandos.

FUNCIONAMIENTO
- Conserva el diseño y las funciones de DevFlow Scanner 1.4.3.
- Rellena automáticamente la carpeta abierta en VS Code.
- Inicia un motor privado en 127.0.0.1:47831.
- El laboratorio continúa limitado a localhost.
- Si la aplicación de escritorio DevFlow está abierta con otra versión, ciérrala antes de abrir la extensión.

VALIDACIÓN
- Windows x64: instalado y probado correctamente.
- Mac Intel/Apple Silicon: compilado de forma cruzada; requiere prueba final en una Mac real.
